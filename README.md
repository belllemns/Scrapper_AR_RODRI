# Aerolineas Argentinas scraper

## Install

```powershell
python -m pip install -e .
```

## Browser scraper

The original scraper uses Chrome to create the shopping session and capture
the offers and ancillary API responses.

```powershell
$env:PYTHONPATH = "src"
python scripts/run_scraper.py --routes BRCBUE --start-date 2026-11-07 --end-date 2026-11-07
```

## Direct API experiment

The `experiment/direct-api` branch includes a browser-free offers client. It
expects a short-lived bearer token in the environment and never stores it in
the source code.

```powershell
$env:AEROLINEAS_ACCESS_TOKEN = "<token>"
$env:PYTHONPATH = "src"
python scripts/run_direct_api.py --origin BRC --destination BUE --date 2026-11-07
```

To inspect the request generated by the site and obtain a local capture for
diagnostics:

```powershell
python scripts/capture_api_request.py --origin BRC --destination BUE --date 2026-11-07
```

Capture files belong in `Downloads` and must not be committed because they
contain session headers.
